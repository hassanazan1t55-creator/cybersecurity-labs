# Day 01: Linux File System & Basic CLI Navigation

## Module Overview
This module covers the core fundamentals of the Linux operating system, focusing on directory structure navigation, system path identification, file listing mechanics, and searching parameters within log files.

## Files in this Directory
- `Day-01-Linux-Navigation.md`: Detailed notes, command cheatsheet, and practical task reflections.
- `README.md`: Overview and summary of Day 01 learning objectives.

## Key Takeaways
- Mastered absolute vs relative path navigation using `cd`, `cd ..`, `cd ~`, and `cd /`.
- Understood hidden file structures (`.filename`) and how to inspect them using `ls -la`.
- Applied text searching within server logs using `grep` during TryHackMe lab exercises.
